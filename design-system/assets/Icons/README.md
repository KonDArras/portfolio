# Icons

Hobby icons from `src/components/icons.jsx`: 20 × 20 viewBox, 1.4 stroke, round caps and joins, no fill.

- `mountain.svg`: Hiking
- `stopwatch.svg`: Triathlon
- `dice.svg`: Dungeons & Dragons
- `mug.svg`: Beer making
- `wave.svg`: Freediving

The source draws them with `stroke="currentColor"` and sets the color to `live`. These copies are pre-inked in `live` (#8fdc6e) because an `<img>` can't inherit color. To recolor, inline the SVG and set `stroke` back to `currentColor`.
