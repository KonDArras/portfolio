# SectionHeading

Section heading: a small mono label in signal, with an optional dim intro line under it.

Use one per page section; the section itself closes with a `line` rule at `space-72` padding. Headings are labels, never banners: do not enlarge them. Consumer supplies `title` and optionally `intro` and an `id` for `aria-labelledby`.

Hand-written from `src/index.css` (`.section h2`, `.page-intro`).
