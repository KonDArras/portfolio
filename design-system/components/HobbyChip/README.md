# HobbyChip

Hobby chip: a glass chip with a `live` line icon and a `text-dim` label that brightens and lifts 2px on hover.

For personal-interest lists. Pass an icon URL from the Icons group. In the site the icons are inline SVG with `currentColor`; the uploaded copies are pre-inked in `live`.

Hand-written from `HobbyChip` in `src/pages/Home.jsx`.
