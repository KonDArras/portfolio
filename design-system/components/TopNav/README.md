# TopNav

Top nav: sticky glass bar with a circular CK monogram and mono links; the active link is `live` with a full underline.

Hover draws a `signal` underline from the left. The monogram is the only 'logo': type in a `line` circle. Consumer supplies `links` and the `active` href. (The site insets it by `gutter-left` on desktop to clear the rail nav.)

Hand-written from `src/components/TopNav.jsx`.
