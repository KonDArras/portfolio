# Stat

Stat: a large mono number in `live` with a glow, over a short `text-dim` caption.

Two or three in a row, `space-40` apart, in the hero. In the site the number counts up (900ms, ease-out cubic) when it scrolls into view. Keep captions under 16ch.

Hand-written from `Stat` in `src/pages/Home.jsx`.
