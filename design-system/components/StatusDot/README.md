# StatusDot

Status dot: an 8px circle, `text-dim` at rest or `live` with a soft pulse when something is running.

The brand's core metaphor: a portfolio read like a monitoring dashboard. Use `live` for current roles and 'up' states only. Pass children to get a mono status line. Pulse stops under reduced motion.

Hand-written from `src/index.css` (`.dot`, `.dot-live`).
