# Terminal

Terminal window: a dark glass frame with traffic-light dots and a mono body; commands in `text` after a `signal` prompt, output in `live`.

The system's signature surface: the site uses it for the deploy demo and for the work history ('upside-down' terminal). It is the only element with a drop shadow (`shadow-terminal`). In the site it types itself out line by line; this component renders given lines, and `typing` shows a line in progress with a blinking caret.

Hand-written from `src/components/Terminal.jsx`.
